Análise Combinatória em C

Programa em C, executado no terminal, que calcula Triângulo de Pascal, Arranjo, Permutação simples e Combinação por meio de um menu interativo.



O programa pede os valores, mostra o resultado e volta ao menu até você digitar 0.




Como executar
bash
gcc analise_combinatoria.c -o analise
./analise



Exemplo
Escolha: 2
Digite o valor de n: 5
Digite o valor de p: 3
A(5,3) = 60
Limitação




Os cálculos usam unsigned long long, então n deve ser no máximo 20 (limite do fatorial).
